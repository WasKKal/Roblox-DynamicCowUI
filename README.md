# DynamicCowUI

**DynamicCowUI** 是一个用于 Roblox 的动画 UI 库（Animated UI Library for Roblox）。

它提供一套轻量、可复用的动画界面组件，帮助开发者在 Roblox 游戏中快速构建流畅、富有动感的 UI 体验。

## ✨ 特性

- 🐄 内置常用动画 UI 组件，开箱即用
- 🎬 基于 `TweenService` 的流畅过渡与动效
- 🎨 可主题化，支持自定义样式与配色
- 🧩 模块化设计，按需引入，零额外负担
- ⚡ 面向性能优化，适配各类设备
